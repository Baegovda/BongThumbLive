# BongThumbLive v2.2 readiness (2026-11-16)

Status: **ready for a v2.2 release on UE 5.8, not released.** No tag or release was made; that needs the owner's go.

## What changed since v2.1 (tag 9b3050e)

### Speed and smoothness (UE 5.7 era, measured then)
- Render-thread governor for offscreen anim renders (no more 15-25 s hitch while new caches are generated). Asynchronous selection loads, non-blocking anim readiness, incremental GC.
- Folder click: fast scan window. Cold scrolling: coarse first frames, off-screen plugin-loaded anims released early (`ReleaseAfterCoarse 2`).
- Measured on 5.7: hitches > 50 ms during generation 69 → 1; selecting 50 anims 97 hitches → 1.

### Correctness
- Tiles that stayed on the stock icon or black, and scrolled-in tiles that waited for a hover, now animate (announce + pool texture re-render, push into every displayed tile size).
- Preview-mesh resolver uses compatible skeletons and same-folder meshes; gives up with a clear log reason and the stock thumbnail.
- Full audit (2026-11-08): guarded load queue, dependency invalidation, job generations, byte leases, bounded cache parsing, spinner clipping. Settings engine-wide since 2026-11-15.

### New UI
- Loading spinner on tiles until their first frame (colour, style Spin/Pulse/Dots/Bar, speed). Korean settings with tooltips.

### UE 5.8 (2026-11-16)
- Port: `EngineVersion 5.8.0`, one API deprecation fixed, builds with no warnings.
- **5.8-only bug fixed:** the 5.8 Content Browser wraps the asset view in `SInvalidationPanel`; widget walks now use `GetAllChildren()`. Without this the plugin finds no asset view on 5.8 and nothing animates.
- **Framing:** animation tiles are framed on the CPU-skinned mesh vertices (`BongThumbLive.TightFraming`, default on). Meshes whose bounds are much larger than the visible mesh (first-person arms) were tiny; now centred and 2-3x larger. Cache key version 3, so old caches regenerate once.
